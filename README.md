### 🚀 Featured Projects

#### 🔗 Centralized Communication Gateway

Generic Spring Boot communication gateway that validates requests and dynamically routes them to internal service endpoints — reducing the need for multiple dedicated integration APIs, with built-in Uptime Kuma health monitoring and audit token generation.

| Layer | Technology |
|---|---|
| Language | Java |
| Framework | Spring Boot, Spring Data JPA |
| Database | MySQL |
| API | REST APIs, RestClient, Swagger |
| Utilities | Lombok |
| Monitoring | Uptime Kuma |

#### 🧠 Local RAG Chat Application *(Personal Project)*

A Retrieval-Augmented Generation (RAG) platform combining semantic search and LLM inference for context-aware document Q&A — ingesting PDF/DOCX/TXT files, chunking text, generating embeddings, and storing vectors in ChromaDB to reduce LLM hallucinations.

[![Readme Card](https://github-readme-stats.vercel.app/api/pin/?username=PremJituri&repo=Local-RAG-Chat&theme=nord&border_color=7dd3fc&title_color=7dd3fc)](https://github.com/PremJituri/Local-RAG-Chat)

| Layer | Technology |
|---|---|
| Language | Java |
| Framework | Spring Boot, Spring AI |
| LLM / Embeddings | Ollama (Llama 3.2, Nomic Embed) |
| Vector Store | ChromaDB |
| Frontend | React 18, Vite |
| File Processing | Apache PDFBox, Apache POI |
| Deployment | Docker Compose |

🔗 [Code](https://github.com/PremJituri/Local-RAG-Chat)
